# RV32I RISC-V Core - RTL to GDSII (OpenLane + Sky130)

A 32-bit RISC-V (RV32I) processor core designed in Verilog and taken through
the full physical design flow using OpenLane and the SkyWater 130nm PDK.

## Status
- [ ] Register file + testbench
- [ ] ALU, decoder, control, branch logic
- [ ] Single-cycle core
- [ ] 5-stage pipeline
- [ ] OpenLane runs: timing, congestion, area tuning

## Tools
Icarus Verilog, GTKWave, OpenLane, Sky130, KLayout
